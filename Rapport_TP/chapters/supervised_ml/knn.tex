\section{KNN Model Configuration and Evaluation}

For the KNN model, several dataset variants were tested, and the final model was trained on the \textbf{normalized data combined with SMOTE+Tomek resampling}. Normalization was essential since KNN is distance-based; without scaling, features with larger numeric ranges would dominate distance computations and bias the model. Hyperparameter tuning was performed using \textbf{Bayesian Search}, which allowed efficient exploration of the parameter space and selection of an optimal configuration focused on maximizing the F1-score.

The best parameters obtained are summarized as follows: Algorithm: \texttt{kd\_tree}, Distance metric: \texttt{Manhattan} (\(p = 1\)), Number of neighbors: \(k = 4\), Weights: \texttt{distance}.
This configuration achieved a \textbf{best cross-validation F1-score of 0.9614}. These exact parameters were then reused to train the \textbf{from-scratch KNN implementation}, ensuring a fair and consistent comparison with the library-based model.
