\section{Overview}

This chapter presents the supervised machine learning models used in this study for forest fire prediction. It describes the learning algorithms, training strategy, and evaluation methodology applied to the engineered dataset. The goal is to assess and compare the performance of different supervised classifiers using a consistent experimental setup.

The models considered include Decision Tree (DT), k-Nearest Neighbors (KNN), and Random Forest (RF). Each subsection details the model configuration, training process, and evaluation results.
