\section{Soil Data Extraction}
The soil dataset was extracted from HWSD2 by resampling the categorical soil raster to a consistent 0.1° grid over the Algeria–Tunisia AOI using mode-based resampling. GeoPandas, shapely, rioxarray, and rasterio were used for AOI handling, raster clipping, reprojection, and grid construction. The HWSD2 Microsoft Access database was queried via pyodbc to retrieve topsoil (D1, 0-20 cm) physical and chemical properties linked through soil mapping unit IDs. NumPy and pandas handled data cleaning, type normalization, joins, and tabular exports, while matplotlib supported rapid spatial sanity checks. The final output is a GIS- and ML-ready soil feature dataset exported as CSV and GeoPackage for downstream fire prediction models. The detailed extraction method Implementation is provided in Annex~\ref{annexe:soil_extraction}.
