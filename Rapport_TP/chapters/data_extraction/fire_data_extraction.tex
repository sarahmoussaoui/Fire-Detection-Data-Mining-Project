\section{Fire Data Extraction}

% \textbf{Fire Dataset Composition}
\label{sec:dataset_composition}

The dataset utilized for this analysis is a composite structure derived from two distinct data sources corresponding to fire incidents recorded in \textbf{Algeria} and \textbf{Tunisia}. The original data for each country is provided in a separate CSV file.

\textbf{Data Integration and Structure}

The core process involved the simple integration of these two national datasets to form a unified, comprehensive file. This merged dataset provides a consistent structure across all observations, which is essential for comparative analysis.

The resultant dataset comprises 15 columns, detailing geographical, temporal, and radiative properties of the detected fire events. The complete set of variables is as follows:
\begin{itemize}
    \item \texttt{latitude}, \texttt{longitude}: Geographical coordinates of the fire pixel.
    \item \texttt{acq\_date}, \texttt{acq\_time}: Time and date of acquisition.
    \item \texttt{satellite}, \texttt{instrument}: Sensor and platform used for detection (e.g., N20, VIIRS).
    \item \texttt{bright\_ti4}, \texttt{bright\_ti5}: Brightness temperatures (in Kelvin) measured by channels I4 and I5.
    \item \texttt{frp}: Fire Radiative Power (in MW), a key metric for fire intensity.
    \item \texttt{scan}, \texttt{track}: Dimensions of the fire pixel (in km).
    \item \texttt{confidence}: Confidence level of the fire detection.
    \item \texttt{version}, \texttt{daynight}, \texttt{type}: Auxiliary identifiers.
\end{itemize}
